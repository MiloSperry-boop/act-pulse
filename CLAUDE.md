# ACT — project context for Claude

Personal ACT-prep PWA for Milo (high school student). Display name is **"ACT"**;
the repo/URL/DB keep the original `act-pulse` identifiers — do NOT rename them,
existing installs and IndexedDB data depend on it.

## Key facts
- **Live:** https://milosperry-boop.github.io/act-pulse/ (GitHub Pages, deploys
  automatically via `.github/workflows/deploy.yml` on push to `main`)
- **Repo:** MiloSperry-boop/act-pulse (public)
- Milo uses it installed on his iPhone via Safari Add to Home Screen. iOS bakes
  the name/icon at install time — icon/name changes require delete + re-add
  (export progress first from Settings).
- Naming history (all 2026-07-16): ACT Pulse → Summit → **ACT**. Icon is a
  font-free geometric dark-blue (#1e3a8a) "ACT" on white, generated by
  `node scripts/gen-icons.mjs`.

## Architecture notes
- React/TS/Vite/Dexie/Zustand/Zod; HashRouter; vite-plugin-pwa with
  `autoUpdate` + skipWaiting + hourly/foreground update checks (no update
  prompt — it applies silently).
- Adaptive engine in `src/engine/` (Beta-mastery, weakness diagnosis, spaced
  repetition, weighted selection). Content in `src/content/` — authored +
  seeded procedural generators; ALL content must pass `src/content/validate.ts`
  (tests enforce it).
- Scroll is app-like: body is locked (`position:fixed; overflow:hidden`), each
  screen scrolls internally — this keeps the glass bottom nav immovable during
  iOS rubber-banding. Don't reintroduce page-level scrolling. Pinch-zoom is
  intentionally disabled.
- SVA generator: verb sets are template-scoped (BE_ONLY vs LINKING) to avoid
  ungrammatical sentences — keep the regression test passing.

## Workflow
- Verify with: `npm run typecheck && npm run lint && npm test && npm run build`
- Verify UI changes in a real browser before claiming done (Milo's standard).
- **GitHub quirk:** `gh auth status` false-negatives ("keyring invalid") but the
  token WORKS. Push with:
  `git -c credential.helper='!f() { echo username=x-access-token; echo "password=$(gh auth token)"; }; f' push origin main`
  The sandbox also mangles some authenticated GitHub API GETs — verify deploys
  by polling the live URL, not the Actions API.
